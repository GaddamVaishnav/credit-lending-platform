# Credit Platform — AWS Deployment

## What gets deployed:

Resume Skill          → AWS Service Used
─────────────────────────────────────────
Spring Boot           → ECS / EC2
Microservices         → 6 separate containers
Kafka                 → Amazon MSK (Managed Kafka)
Kubernetes            → Amazon EKS
MySQL                 → Amazon RDS
AWS Cloud             → EC2, ECS, RDS, MSK, S3
Jenkins               → Jenkins on EC2
Git                   → GitHub + CI/CD
Maven                 → Build tool in Jenkins
Log4j                 → CloudWatch Logs
Angular               → S3 + CloudFront
Docker                → ECR + ECS
